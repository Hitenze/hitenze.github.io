ParGeMSLR: Parallel Generalized Multilevel Low-Rank Preconditioner

ParGeMSLR (Parallel Generalized Multilevel Schur Low-Rank) is an MPI-based C++ library for solving large, sparse symmetric and nonsymmetric linear systems. Its purely algebraic preconditioner combines a multilevel Schur-complement hierarchy with low-rank corrections.

Main Developer

SchurCheb: Schur Complement Chebyshev Eigenvalue Solver

SchurCheb is an MPI-based C++ research code for computing partial spectral factorizations of matrix pencils via Chebyshev approximation. The distributed-memory implementation computes the eigenvalues and corresponding eigenvectors of a large, sparse, real symmetric positive-definite matrix pencil that lie within a target interval.

C++MPICUDA

Main Developer

SchurILU: NumPy/SciPy ILU Baselines

SchurILU is a NumPy/SciPy library for incomplete LU preconditioners with explicit Schur-complement support. It provides reproducible ILU baselines for research in iterative solvers and learning-based preconditioning.

HiGP: High-Performance Package for Large-Scale Gaussian Processes

HiGP is a high-performance Python package for large-scale Gaussian process regression and classification. It provides C++ and Python interfaces for efficient training and prediction on large datasets.

hypre: High-Performance Preconditioners

hypre is a library of high-performance preconditioners and solvers featuring multigrid methods for the solution of large, sparse linear systems of equations on massively parallel computers. I contribute to the development of GPU-accelerated incomplete LU preconditioners.
