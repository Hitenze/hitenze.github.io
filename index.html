I develop mathematical foundations, algorithms, and efficient implementations in scientific machine learning, stochastic optimization, and high-performance computing.

Research

  • Scientific Machine Learning

    Multiscale neural representations of Green’s functions and learning-augmented preconditioners that encode the structure of the underlying operator.

  • Stochastic Optimization

    Preconditioning for stochastic gradient methods and variance reduction in trace and log-determinant estimators, with applications to Gaussian processes and large language model training.

  • High-Performance Computing

    Scalable algorithms and implementations that account for communication costs, parallelism, GPU execution, and mixed precision.

Common foundation

Numerical linear algebra

Numerical linear algebra is the common thread, connecting my work on learning-augmented PDE solvers, preconditioned methods for large-scale learning, and scalable algorithms for modern computing architectures.

Software

  • ParGeMSLR — Main developer

    An MPI/C++ implementation of a parallel multilevel Schur-complement low-rank preconditioner for large sparse linear systems.

  • SchurCheb — Main developer

    A distributed Chebyshev eigensolver for partial spectral factorizations of matrix pencils.

  • SchurILU — Main developer

    NumPy/SciPy ILU baselines with Schur-complement support, available on PyPI.

  • HiGP — Co-developer

    A high-performance Python package for large-scale Gaussian processes.

  • hypre — Contributor

    GPU-accelerated incomplete LU preconditioners.
