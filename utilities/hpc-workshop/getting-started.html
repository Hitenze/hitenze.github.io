Getting Started: Your First HPC Job

Follow this step-by-step tutorial to run your first high-performance computing job successfully

Getting Started (VS Code path)

Local laptop checklist

  • • Stable Internet and power
  • • VS Code + “Remote – SSH” extension installed
  • • SSH available (macOS/Linux built‑in; Windows OpenSSH/WSL)
  • • Cluster details: username, host (cluster.address), MFA
  • • Optional: zip tool for large folders

VS Code quick setup

  • • Install VS Code and the “Remote – SSH” extension
  • • Connect: Ctrl/Cmd+Shift+P → Remote‑SSH: Connect to Host… → your_user@cluster.address → enter password/MFA
  • • Connected when the bottom‑left shows “>< SSH”
  • • Open Folder: Explorer → Open Folder… → choose /home/your_user → create hpc101/

File transfer

  • • Use VS Code Explorer: drag files in/out
  • • Or right‑click Upload/Download in Explorer
  • • Tip: zip large folders before upload

Your First HPC Job: "Hello World"

Let's create and submit a simple job to verify everything works correctly.

1

Create a Working Directory

Organize your work by creating a dedicated directory for this tutorial.

$ cd $HOME                        # Go to home directory
$ mkdir hpc_tutorial               # Create tutorial directory
$ cd hpc_tutorial                # Enter the directory
$ pwd                            # Verify location
2

Create a Simple Program

Create a basic C program that demonstrates HPC environment information.

Create hello_hpc.c:

$ nano hello_hpc.c               # Create and edit file

Copy this C code:

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/utsname.h>

int main() {
    struct utsname system_info;
    char hostname[256];
    char *slurm_job_id;
    char *slurm_node_list;
    
    // Get system information
    uname(&system_info);
    gethostname(hostname, sizeof(hostname));
    
    // Get Slurm environment variables
    slurm_job_id = getenv("SLURM_JOB_ID");
    slurm_node_list = getenv("SLURM_JOB_NODELIST");
    
    printf("=== HPC Environment Information ===\n");
    printf("Hello from HPC cluster!\n");
    printf("Hostname: %s\n", hostname);
    printf("Operating System: %s %s\n", system_info.sysname, system_info.release);
    printf("Architecture: %s\n", system_info.machine);
    
    if (slurm_job_id) {
        printf("Slurm Job ID: %s\n", slurm_job_id);
    }
    if (slurm_node_list) {
        printf("Slurm Node List: %s\n", slurm_node_list);
    }
    
    printf("Process ID: %d\n", getpid());
    printf("User ID: %d\n", getuid());
    printf("===============================\n");
    
    return 0;
}

💡 Tip: In nano, press Ctrl+O to save, then Ctrl+X to exit.

3

Create a Job Script

Create a Slurm job script to compile and run your program.

Create run_hello.sh:

$ nano run_hello.sh             # Create job script

Copy this job script:

#!/bin/bash

# Job identification
#SBATCH --job-name=hello_hpc
#SBATCH --output=hello_hpc_%j.out
#SBATCH --error=hello_hpc_%j.err

# Resource allocation (minimal for this example)
#SBATCH --nodes=1
#SBATCH --ntasks=1
#SBATCH --cpus-per-task=1
#SBATCH --mem=1G
#SBATCH --time=00:05:00

# Specify partition (adjust for your cluster)
#SBATCH --partition=debug

# Print job information
echo "=========================================="
echo "Job started on: $(date)"
echo "Job ID: $SLURM_JOB_ID"
echo "Node: $SLURM_JOB_NODELIST"
echo "Working directory: $(pwd)"
echo "=========================================="

# Go to the directory where the job was submitted
cd $SLURM_SUBMIT_DIR

# Load necessary modules (adjust for your cluster)
module purge
module load gcc

# Compile the program
echo "Compiling hello_hpc.c..."
gcc -o hello_hpc hello_hpc.c

# Check if compilation was successful
if [ $? -eq 0 ]; then
    echo "Compilation successful!"
    echo "Running the program..."
    echo "=========================================="
    
    # Run the program
    ./hello_hpc
    
    echo "=========================================="
    echo "Program execution completed."
else
    echo "Compilation failed!"
    exit 1
fi

echo "Job completed on: $(date)"

⚠️ Note: Adjust the partition name (debug) and module names to match your cluster configuration.

4

Submit and Monitor Your Job

Submit the job and monitor its progress.

# Submit the job
$ sbatch run_hello.sh
Submitted batch job 12345

# Check job status
$ squeue -u $USER
             JOBID PARTITION     NAME     USER ST       TIME  NODES NODELIST(REASON)
             12345     debug hello_hp username  R       0:01      1 compute-001

# Wait for completion, then check output
$ ls -la
total 16
-rw-r--r-- 1 user group  1234 Jan 15 10:30 hello_hpc_12345.out
-rw-r--r-- 1 user group     0 Jan 15 10:30 hello_hpc_12345.err
-rwxr-xr-x 1 user group  8760 Jan 15 10:30 hello_hpc
-rw-r--r-- 1 user group  1456 Jan 15 10:29 hello_hpc.c
-rw-r--r-- 1 user group  1234 Jan 15 10:29 run_hello.sh

🎉 Success Indicators:

  • • Job submission returns a job ID
  • • Job status shows "R" (Running) then disappears (Completed)
  • • Output file created with job ID in filename
  • • Error file is empty or contains only warnings

Performance Analysis

Check job efficiency:

$ sacct -j 12345 --format=JobID,JobName,Elapsed,CPUTime,MaxRSS,State

Sample output:

JobID JobName Elapsed CPUTime MaxRSS State
------------ ---------- ---------- ---------- ---------- ----------
12345 hello_hpc 00:00:02 00:00:02 1234K COMPLETED
12345.ba+ batch 00:00:02 00:00:02 1234K COMPLETED

✅ What This Tells Us:

  • • Job completed successfully (COMPLETED state)
  • • Very fast execution (2 seconds)
  • • Low memory usage (1.2 MB)
  • • Efficient for this simple task

📊 Efficiency Note:

This job was over-provisioned (requested 1GB memory, used 1.2MB). For real applications, optimize resource requests based on actual usage.
